# LanFu 管理员部署说明

## 产品边界

LanFu 0.1.0 是员工分别安装、分别使用的 Agent 运行产品，不是 OCE 式集中式多人管控平台。

## 版本记录

- 对外版本：LanFu 0.1.0
- 上游基线：OpenClaw 2026.9.6
- 发布标签：lanfu-v0.1.0

## 模型连接

员工设备可以通过公司网络或 Tailscale 访问公司 vLLM。不要把某个固定 Tailscale 地址写死为唯一可用地址；应通过安装后配置或管理员配置模板注入。

当前只读验证过的模型服务为 OpenAI 兼容接口，提供 qwen38 和 qwen38-think。

## 数据迁移

旧版 .openclaw 迁移到新版 .lanfu 前必须备份。迁移失败时保留旧目录，不要手工删除，也不要把两个目录直接合并。
