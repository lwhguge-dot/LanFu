# LanFu 0.4.35

快速修补包：安装器清理缺口收尾 + 关于页版本行数据驱动 + zh-CN 更新排查/登录引导文案补齐。无新功能。

## 修复与改进

1. **安装器清理 runtime `is-*.tmp` 孤儿**：Inno 解包中断遗留的 `is-*.tmp` 升级时从不清理（真机 0.4.25/26 时代遗留 92.8MB）。`[InstallDelete]` 新增 `{app}\runtime\is-*.tmp` 与 `{app}\is-*.tmp`；重复安装 smoke 预埋假孤儿文件并断言被清，回归即构建失败。
2. **关于页「基于 core …构建」改为数据驱动**：文案改为 `Built on core {version}` 插值模板，版本号取自构建身份（buildInfo.version），核心升级后不再过时；zh-CN/zh-TW 译文同步为插值形式。
3. **zh-CN 缺译补齐 30 条**：更新排查/失败原因（triage、握手超时、外部监督进程、托管服务移交等 14 条）、登录/配对引导（lede、setupCodeHint、dashboard/network 步骤 6 条）、连接审批与设备设置码、云端工作节点检查点、插件安装未应用等提示——此前全部英文回退。zh-CN 目录缺译清零（其余 18 语言维持英文回退，既有债务）。

## 调查后不改的项（0.4.33 截图审查的三个"疑似缺陷"确认为设计意图）

- 设置页侧栏底部"模型"半行显示：导航共 28 项、容器 `overflow-y:auto` 可正常滚动，半行是可滚动提示，非截断缺陷；
- 聊天页助手消息无气泡背景：CSS 注释明确"Assistant replies render as a flat text stream; user and forwarded messages keep bubble cards"，设计如此；
- 左侧竖排短横线与消息区"重叠"：实测为对话位置导航栏（sticky 置于独立栏位），与消息文本无几何重叠。

## 验证

- 开发侧：tsgo core/ui/scripts 零错误；about+build-info 单测 15/15 绿（含 upstream 插值断言）；zh-CN 缺译清单复扫为 0；smoke 新增 is-*.tmp 守卫。
- 用户侧：发布后本机 0.4.34→0.4.35 升级复验（真机 92.8MB 孤儿文件应被清除）。
